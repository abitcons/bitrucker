Built to refuse unsafe actions

Safety controls are product features.

Automation is useful only when it can stop, explain itself, and recover cleanly.

Trade-only key validation

Connections are checked with read-only calls. Withdrawal, transfer, missing trade permission, and missing IP restriction are rejected.

Tenant isolation

Customer credentials, runtime state, bots, and pair registries use separate namespaces. Server-owner keys cannot be inherited.

Emergency entry lock

An audited, durable switch blocks new entries while leaving stop, close, and protective-exit paths available.

Account protection

TOTP MFA, one-time recovery codes, login throttling, CSRF protection, secure cookies, and durable action auditing are built in.
